AMIS Runtime Documentation

This document describes all available function in the AMIS node API.

batch_create

Create a new empty batch with specified dimensions and settings.

Parameters

NameTypeDescriptionDefault
batch_name string Name of the batch empty
batch_width double Width of the batch in millimeters 0.0
batch_depth double Depth of the batch in millimeters 0.0
batch_height double Height of the batch in millimeters 0.0
slice_resolution double Slice resolution in DPI 300.0
slice_thickness double Slice thickness in millimeters 0.1

batch_open

Open a 3MF or CAMSPEC batch file into the current context.

Parameters

NameTypeDescriptionDefault
file_name string Name of the file to open required

batch_recover

This action allows you to recover a batch that has partially failed during printing by removing all parts that are completely below a specified height.

Parameters

NameTypeDescriptionDefault
failure_height double The height in mm below which parts will be removed 0.0

batch_resize

Resize the current batch to match the dimensions of a different printer.

Parameters

NameTypeDescriptionDefault
batch_width double Width of the batch in millimeters 0.0
batch_depth double Depth of the batch in millimeters 0.0
batch_height double Height of the batch in millimeters 0.0

batch_save_as

Save the current batch to a 3MF file. The function will overwrite any existing file.

Parameters

NameTypeDescriptionDefault
file_path string The path to save the batch to required

batch_settings_save

Save the output settings for this batch.

Parameters

NameTypeDescriptionDefault
slice_resolution double Slice resolution in DPI 300.0
slice_thickness double Slice thickness in millimeters 0.1

batch_unplaced

This action creates a new batch containing all parts that are currently outside the build area. Unsaved changes to the current batch will be lost.

Parameters

NameTypeDescriptionDefault
name string The name of the new batch file empty

nest_box_parts

This function will create a sinterbox around the currently selected parts.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings An array of part numbers to box []
box_type string The type of box to create, either 'cube' or 'free' "cube"
box_calculation_method string The method to use to calculate the box, either 'auto' or 'manual' "auto"
beam_thickness number The thickness of the beams in mm to use when 'manual' box calculation is selected 1.5
max_hole_size number The maximum hole size in mm to use when 'manual' box calculation is selected 10.0
create_label boolean If true, a label will be created on the box false
label_text string The text to use for the label on the box ""

nest_clear

This action will remove all unlocked parts from the build area, allowing you to start a fresh nesting session.


nest_delete_unplaced

This action will delete all the unplaced instances from the batch. Parts that have no placed instances at all will be removed as well.


nest_execute

This action will arrange all parts inside the print box in an optimal way to minimize wasted space. The nesting algorithm will take into account the part dimensions, the specified gaps and the print bed dimensions. After nesting, all parts will be repositioned according to the calculated layout. Unplaced parts remain outside the buildbox.

Parameters

NameTypeDescriptionDefault
stop_at_iteration uint32 The iteration at which to stop nesting (for resuming interrupted nestings) MAX_INT
time_out double The time-out after which we stop nesting (in seconds, 0 = no time-out) 0.0

nest_lock

This action will lock the position of all parts that are currently placed inside the build box. Locked parts cannot be moved or modified until they are unlocked again. They will also stay in their current position if a new nesting operation is performed.


nest_settings_save

Store the settings to use for the nesting operation, omitting a parameter will leave it unchanged.

Parameters

NameTypeDescriptionDefault
nest_gap double The gap between nested parts in mm 4.0
box_gap double The gap between nested parts and the build box in mm 2.0
nest_to_density_active bool Enable nesting to density false
nest_to_density double The target density to reach when nesting to density (in %) 11.0
nest_layer_density_active bool Enable layer density control false
nest_layer_density double The maximum layer density to allow (in %) 13.0
nest_height_limit double The maximum height to use for nesting (0 = use entire buildbox) 0.0

nest_unlock

This action will unlock all parts that are currently locked in position inside the build box, allowing them to be moved again. Initiating a nesting will cause these parts to be renested as a consequence.


part_center

Center the specified part in the active batch.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to center. required
instance_idx number Zero-based index of the instance to center, if not specified, all instances will be centered. optional

part_delete

Delete the specified part from the batch.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to delete. required
instance_idx number Zero-based index of the instance to delete, if not specified, all instances will be deleted. optional

part_duplicate

This action will create a copy of the selected part. The new part will receive the same transformation and properties as the original part. It is possible to pass a new_part_number to the duplicated part to allow further operations on this part. If no new_part_number is given, one will be automatically assigned. When a new_part_number is specified and it is already in use, the duplicate will fail for that part.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to duplicate required
new_part_number string The part number to assign to the duplicated part (optional)

part_import

Import one or more parts into the current build area from STL, STEP or 3MF files. The imported parts will be automatically repaired and prepared for nesting. It is possible to pass a part_number to the imported part to allow further operations on this part. If no part_number is given, one will be automatically assigned. When a part_number is specified and it is already in use, the import will fail for that part.

Parameters

NameTypeDescriptionDefault
file_path string The file path of the part to import required
part_number string The part number to assign to the imported part (optional)

part_priority

This action will set the nesting priority of the selected parts in a range of 0-100. Parts with a higher priority will be favored during the nesting process.

Parameters

NameTypeDescriptionDefault
priority_value integer The priority value to set for the selected parts (0-100) 50

part_settings_save

Save any of the settings of the parts. All optional values can be omitted, and they will leave that setting unchanged. If an instance index is provided, the instance position can also be modified. An instance is a single copy of the part.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to modify required
rotation_x double The rotation around the X axis (in degrees) (optional) 0.0
rotation_y double The rotation around the Y axis (in degrees) (optional) 0.0
rotation_z double The rotation around the Z axis (in degrees) (optional) 0.0
scale_x double The scaling along the X axis (in percent) (optional) 100.0
scale_y double The scaling along the Y axis (in percent) (optional) 100.0
scale_z double The scaling along the Z axis (in percent) (optional) 100.0
copies int The number of copies to create for this part (reducing it may remove instances of the part that are already placed) (optional) 1
nest_gap double The gap to use when nesting this part (optional) 4
allow_x_rotation bool Allow rotation around the X axis when nesting (optional) false
allow_y_rotation bool Allow rotation around the Y axis when nesting (optional) false
allow_z_rotation bool Allow rotation around the Z axis when nesting (optional) false
instance_idx int The index of the instance to modify (optional) 0
instance_x double The X position of the instance to modify (optional, ignored if instance_idx not provided) 0.0
instance_y double The Y position of the instance to modify (optional, ignored if instance_idx not provided) -90.0
instance_z double The Z position of the instance to modify (optional, ignored if instance_idx not provided) 0.0
lock_position bool Lock the position of the instance to modify (optional, ignored if instance_idx not provided) false

part_shelling_execute

This action will create a shell around the selected part. You can specify the shell thickness and whether you want to add a lattice structure inside the shell for added strength.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to shell required
create_shell boolean Whether to create a shell around the part, if set to false, an existing shell will be removed false
shell_thickness number The thickness of the shell in mm 4.0
create_lattice boolean Whether to create a lattice structure inside the shell false
lattice_beam_length number The length of the lattice beams in mm 8.0
lattice_beam_thickness number The thickness of the lattice beams in mm 2.0

part_show_log

Show the healer log entries for all meshes in the specified part.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part whose mesh log to display required

slicer_execute

This action will slice the current batch. Depending on the output type, you need to specify a folder or a filepath as output location. Resolution and slice thickness are taken from the batch settings. When slicing to 3MF, the output file will use the 3MF Slice Extension for storing the slice information.

Parameters

NameTypeDescriptionDefault
output_type string Type of output to generate (tiff, svg, cli, sli, 3mf) tiff
output_location string The output location for the sliced files (folder for tiff, filepath for others) required

slicer_export_3mf

This action will export the current batch as a 3MF file that can be used in other slicing applications. The main difference with a regular save is that all parts outside of the batch will not be saved, and all metadata will be stripped from the output file.

Parameters

NameTypeDescriptionDefault
3mf_file string The path to the 3MF file to export to required
hp_format boolean Set to true to export this file in the HP3MF format false

slicer_export_stl

This action will export the complete batch as a single STL file that can be used in other slicing applications.

Parameters

NameTypeDescriptionDefault
stl_file string The path to the STL file to export to required

slicer_parts_list

This action will export a file containing the list of parts in the current batch along with their dimensions and volumes. Depending on the format, additional information can be stored in the output file.

Parameters

NameTypeDescriptionDefault
file_path string The filepath to export the parts list to required
part_list_format string The format to use for the parts list ('csv', 'html' or 'json') required
part_list_unplaced boolean Whether to include unplaced parts in the parts list (only for json format) false
part_list_batch boolean Whether to include batch information in the parts list (only for json format) false
part_list_density boolean Whether to include density information in the parts list (only if batch info is requested), this will make the export slower false
