AMIS Runtime Documentation

This document describes all available function in the AMIS node API.

returnCurrentState()

This function in amis.js takes no parameters and returns the current batch state as a JavaScript object parsed from the JSON export, including placed and unplaced parts and batch information.

It executes all queued commands before returning the state and queues the saved batch to be reopened on the next execute() call.

See the JSON export format for details of the returned data.

link_hp_job_send

Sends the current batch to the HP MJF for printing. This call will fail if the assigned printer is not an HP printer.


mesh_face_orient

In Part View, select a face to turn its outward normal down. A subsequent Z-axis rotation minimizes the bounding-box footprint of all models in the part, with the longer side along X (width >= depth). Escape or clicking Face Down again cancels picking.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to orient required

mesh_orient

Rotate the specified part so the volume of its axis aligned bounding box is as small as possible.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to orient. required

nest_apply_part_settings

Apply the batch's rotation permissions to all top-level parts after confirmation as one undoable change. Other part properties and group members are preserved.


nest_box_parts

This function will create a sinterbox around the currently selected parts as one undoable change. Redo restores the retained box and layout without recalculation.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings An array of part numbers to box []
box_type string The type of box to create, either 'cube' or 'free' "cube"
box_calculation_method string The method to use to calculate the box, either 'auto' or 'manual' "auto"
beam_thickness number The thickness of the beams in mm to use when 'manual' box calculation is selected 1.5
max_hole_size number The maximum hole size in mm to use when 'manual' box calculation is selected 10.0
create_label boolean If true, a label will be created on the box false
label_text string The text to use for the label on the box ""

nest_clear

This action will unplace all unlocked top-level instances as one undoable change, allowing you to start a fresh nesting session. Group members are preserved. Undo restores the original layout and rotations.


nest_delete_unplaced

This action will delete all top-level instances that do not intersect the build box as one undoable change. Parts without remaining instances are removed as well. Group copies are treated as single instances; their members are preserved.


nest_execute

This action will arrange all parts inside the print box in an optimal way to minimize wasted space. The nesting algorithm will take into account the part dimensions, the specified gaps and the print bed dimensions. After nesting, all parts will be repositioned according to the calculated layout. Unplaced parts remain outside the buildbox. Consecutive solution updates form one undoable change until the nesting command is finalized.

Parameters

NameTypeDescriptionDefault
stop_at_iteration uint32 The iteration at which to stop nesting (for resuming interrupted nestings) MAX_INT
time_out double The time-out after which we stop nesting (in seconds, 0 = no time-out) 0.0

nest_lock

This action will lock the position of all parts that are currently placed inside the build box as one undoable change. Locked parts cannot be moved or modified until they are unlocked again. They will also stay in their current position if a new nesting operation is performed.


nest_settings_save

Store the settings to use for the nesting operation as one undoable change, preserving the batch dimensions. Omitting a parameter will leave it unchanged.

Parameters

NameTypeDescriptionDefault
nest_gap double The gap between nested parts in mm 4.0
box_gap double The gap between nested parts and the build box in mm 2.0
nest_to_density_active bool Enable nesting to density false
nest_to_density double The target density to reach when nesting to density (in %) 11.0
nest_layer_density_active bool Enable layer density control false
nest_layer_density double The maximum layer density to allow (in %) 13.0
nest_height_limit double The maximum height to use for nesting (0 = use entire buildbox) 0.0
nest_spread_parts bool Enable spreading of parts in the build box to reduce density false
nest_allow_x_rotation bool Allow rotation around the X axis Current Value
nest_allow_y_rotation bool Allow rotation around the Y axis Current Value
nest_allow_z_rotation bool Allow rotation around the Z axis Current Value

nest_unbox_parts

Removes the sinterbox and releases each group's non-box members, unplacing their unlocked instances. Multiple groups are unboxed as one undoable change; undo restores their boxes and original layouts.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings Part numbers of the groups to unbox. []

nest_unlock

This action will unlock all parts that are currently locked in position inside the build box as one undoable change, allowing them to be moved again. Initiating a nesting will cause these parts to be renested as a consequence.

Center the specified part in the active batch.

Parameters

part_change_name

Parameters

NameTypeDescriptionDefault

part_delete

Delete the specified part or instance from the batch through the undo history. Deleting multiple selected parts is grouped into one undo step.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to delete. required
instance_idx number Zero-based index of the instance to delete, if not specified, all instances will be deleted. optional

part_duplicate

This action will create an undoable copy of the selected part. The new part will receive the same transformation and properties as the original part. It is possible to pass a new_part_number to the duplicated part to allow further operations on this part. If no new_part_number is given, one will be automatically assigned. When a new_part_number is specified and it is already in use, the duplicate will fail for that part. Duplicating multiple selected parts is grouped into one undo step.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to duplicate required
new_part_number string The part number to assign to the duplicated part (optional)

part_group

Groups all currently selected parts into a new PartGroup as one undoable change. The action is disabled when no parts are selected or when at least one selected part is already a group.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings Part numbers of the parts to group. []

part_import

Import one or more parts into the current build area from STL, STEP or 3MF files. The imported parts will be automatically repaired and prepared for nesting. It is possible to pass a part_number to the imported part to allow further operations on this part. If no part_number is given, one will be automatically assigned. When a part_number is specified and it is already in use, the import will fail for that part.

Parameters

NameTypeDescriptionDefault
file_path string The file path of the part to import required
file_list array File paths to import as one undo step, instead of file_path. Failed files are skipped.
part_number string The part number to assign to the imported part (optional)

part_lock

This action will lock the position of all instances of the currently selected parts that are placed inside the build box as one undoable change. Locked parts cannot be moved or modified until they are unlocked again. They will also stay in their current position if a new nesting operation is performed.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings The part numbers of the parts to lock. required

part_priority

This action will set the nesting priority of the selected parts in a range of 0-100 as an undoable change. Parts with a higher priority will be favored during the nesting process. Multiple selected parts are changed in one undo step. Omitting priority_value toggles between 100 and 50.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to modify required
priority_value integer The priority value to set for the selected parts (0-100) 50

part_repair

Runs the MeshHealer repair pipeline on every model of the selected part, attempting to turn its mesh(es) into a closed, watertight, 2-manifold mesh. If a mesh cannot be fully repaired, it is flagged for alpha-wrapping instead. Changes are undoable; redo restores the retained meshes without recalculation.


part_settings_save

Save any of the settings of the parts. All optional values can be omitted, and they will leave that setting unchanged. If an instance index is provided, the instance position can also be modified. An instance is a single copy of the part.

scale_x double The scaling along the X axis (in percent) (optional) 100.0
scale_y double The scaling along the Y axis (in percent) (optional) 100.0
scale_z double The scaling along the Z axis (in percent) (optional) 100.0
copies int The target number of copies (minimum 1). Changes are undoable; reducing the count removes trailing instances, including placed ones (optional) 1

allow_x_rotation bool Allow rotation around the X axis when nesting (optional, undoable) Current Value
allow_y_rotation bool Allow rotation around the Y axis when nesting (optional, undoable) Current Value
allow_z_rotation bool Allow rotation around the Z axis when nesting (optional, undoable) Current Value
instance_idx int The index of the instance to modify (optional) 0
instance_x double The X position of the instance to modify (optional, ignored if instance_idx not provided) 0.0

part_shelling_execute

This action will create, replace or remove shelling on the selected part as one undoable change. You can specify the shell thickness and whether you want to add a lattice structure inside the shell for added strength. Redo restores the retained shell without recalculation.

Parameters

NameTypeDescriptionDefault

create_shell boolean Whether to create a shell around the part, if set to false, an existing shell will be removed false
shell_thickness number The thickness of the shell in mm 4.0
create_lattice boolean Whether to create a lattice structure inside the shell false
lattice_beam_length number The length of the lattice beams in mm 8.0
lattice_beam_thickness number The thickness of the lattice beams in mm 2.0

part_split

Splits the selected part into a new PartGroup, with one sub-part for each connected component (edge-connected set of triangles) found in the part's mesh. All instances of the original part are moved to the resulting group. If the part's mesh is already a single connected component, a dialog informs the user instead of performing the split. The split is one undoable change; redo restores the retained group without recalculation.

Parameters

NameTypeDescriptionDefault
part_number string The part number of the part to split. required

part_ungroup

Dissolves all currently selected PartGroups, releasing each non-box subpart back into the batch with its existing instances. Multiple groups are ungrouped as one undoable change. The action is disabled when no groups are selected.

Parameters

NameTypeDescriptionDefault
part_numbers array of strings Part numbers of the groups to ungroup. []

Parameters

slicer_execute

This action will slice the current batch. Depending on the output type, you need to specify a folder or a filepath as output location. Resolution and slice thickness are taken from the batch settings. When slicing to 3MF, the output file will use the 3MF Slice Extension for storing the slice information.

Parameters

NameTypeDescriptionDefault
output_type string Type of output to generate (tiff, svg, cli, sli, 3mf) tiff
output_location string The output location for the sliced files (folder for tiff, filepath for others) required

slicer_export_3mf

This action will export the current batch as a 3MF file that can be used in other slicing applications. The main difference with a regular save is that all parts outside of the batch will not be saved, and all metadata will be stripped from the output file.

Parameters

NameTypeDescriptionDefault
3mf_file string The path to the 3MF file to export to required

slicer_export_stl

This action will export the complete batch as a single STL file that can be used in other slicing applications.

Parameters

NameTypeDescriptionDefault
stl_file string The path to the STL file to export to required
multi bool If true, export each part as a separate STL file false

slicer_parts_list

This action will export a file containing the list of parts in the current batch along with their dimensions and volumes. Depending on the format, additional information can be stored in the output file.

Parameters

NameTypeDescriptionDefault
file_path string The filepath to export the parts list to required
part_list_format string The format to use for the parts list ('csv', 'html' or 'json') required
part_list_unplaced boolean Whether to include unplaced parts in the parts list (only for json format) false
part_list_batch boolean Whether to include batch information in the parts list (only for json format) false
part_list_density boolean Whether to include density information in the parts list (only if batch info is requested), this will make the export slower false
